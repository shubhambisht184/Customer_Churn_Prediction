# Customer Churn Analysis & Business Intelligence Dashboard

Customer retention is one of the most critical challenges for subscription-based businesses. This project presents a comprehensive end-to-end customer churn analytics solution designed to uncover the key factors influencing customer attrition and provide data-driven insights for improving customer retention strategies.

The project begins with a raw customer dataset containing inconsistencies, missing values, duplicates, and formatting issues. Using **Python, Pandas, and NumPy**, extensive data cleaning and preprocessing techniques were applied to transform the data into a structured and analysis-ready format. Feature engineering was performed to create meaningful business metrics such as Customer Lifetime Value, Customer Segmentation, Tenure Groups, Revenue Metrics, and Churn Indicators.

The cleaned dataset was then stored in **MySQL**, where advanced SQL queries were used to analyze customer behavior, churn trends, revenue distribution, contract performance, subscription preferences, payment methods, and geographic patterns. These insights were further visualized through an interactive **Power BI Dashboard** featuring KPI cards, dynamic charts, maps, slicers, and drill-down capabilities.

The dashboard enables stakeholders to monitor churn rates, identify high-risk customer segments, evaluate revenue impact, and make informed business decisions. This project demonstrates practical skills in **data cleaning, data transformation, feature engineering, SQL analytics, business intelligence, and data visualization**, making it a complete real-world Data Analytics solution.

### Key Highlights

* Cleaned and transformed raw customer data using Python and Pandas.
* Performed feature engineering to generate business-focused metrics.
* Conducted exploratory and business-focused analysis using SQL.
* Built an interactive Power BI dashboard with KPIs and dynamic visualizations.
* Identified churn patterns, customer segments, and revenue opportunities.
* Delivered actionable insights to support customer retention and business growth.

### Technologies Used

**Python | Pandas | NumPy | MySQL | SQL | Power BI | Excel**
